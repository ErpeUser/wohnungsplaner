# Modellvorlage

Kopiere diesen Ordner für ein neues Möbelstück und ersetze die Platzhalter im Manifest.

Lege zusätzlich `link.txt` und `quality-report.json` an. Eine Quelle pro Zeile; falls es keine externe Quelle gibt, schreibe den Grund hinein. Der Auditbericht muss offene Maße, fehlende Meshes oder fehlende PBR-Texturen ausdrücklich als offen dokumentieren.
